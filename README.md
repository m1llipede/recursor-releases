# Recursor Releases

Public release artifacts for **Recursor** by PlayOptix — a real-time WebGL video feedback synthesizer for live VJ performance.

The application source lives in a private repo. This repo only hosts signed, notarized download binaries and the `latest.yml` metadata used by the auto-updater.

## Downloads

Latest release: see the [Releases tab](../../releases) above.

- **Windows** — `Recursor-X.Y.Z-x64.exe` — portable .exe, no installer.
- **Mac (Apple Silicon)** — `Recursor-X.Y.Z-arm64.dmg` — signed + notarized.
- **Mac (Intel)** — `Recursor-X.Y.Z-x64.dmg` — signed + notarized.
